The gutanteed GitHub setup for syncing changes:

Create repository on the GitHub website.

Using a shell (PowerShell,  Termux, MacOS Terminal etc.), Clone the repository to selected local location.

(If there's an error: "cannot Clone because the repository is empty" simply go back to the repository and upload one file, this is done in the settings)

Using the shell, GitHub for desktop, the Git plugin for Obsidian, GitSync (used for android and the setup is different,  but be sure that you setup for manual sync):

1. use the following commands for shell: 
2. cd into the drive where the selected location will live.
3. From that location type: git clone "the https of the repository.git" Be sure to put the address in quotation marks.
4. Press enter.

## If Cloning multiple repositories at once:

Using any Shell: (e.g. PowerShell etc.):
 cd into the designated local location. 
 From that location: git clone "https.git address; https .git address; https .git address" remember to use " " marks from the first https to the last .git. Then Press enter. And Viola!!
